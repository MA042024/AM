Rutting Test
Functionalities
  • Save new records  
  • Load and View records  
  • Update existing records  
  • Download records  
Fields marked with an asterisk (*) are required.  

The following fields are semi-mandatory: Grain Size Distribution, Binder Content, Penetration and Voids.  
Save Records: You can save new records to the database using this form. Follow these steps:
  1. On the right sidebar, click on the performance tests tab.
  2. Select the test or tests you desire. You can select multiple tests to fill out at the same time.
  3. Click Apply. The form is now ready to be filled out
  4. Fill in all the fields with the data you have, especially the required fields.
  5. Click the Save button, then click Confirm.
The saved records are stored in the database in an XML document format. If multiple tests were selected, multiple records will be saved. Make sure to save the records to the database before exiting the page to avoid losing any data.

For more information, please check the Tutorial page.
Load and View Records: You can load records either from the database or from your own device, depending on your preference. To do this, use the Upload form located at the top of the page. Follow these steps:
  1. Select a source: AsphaltMine Database or your own device.
  2. Choose a record from the source.
  3. Specify the elements to upload from the list: Data Source, Mixture, Sample Properties, Results or General Notes.
  4. Click the Load button.
Once the records are successfully loaded, you will be able to view the details in a user-friendly format. Where applicable, you can visualize the data through graphs by clicking 📈.

For more information, please check the Tutorial page.
Update Records: You have the ability to update existing records directly within the database. This feature allows you to modify or correct data as necessary, ensuring the database remains current with the latest information. To update a record, follow these steps:
  1. Go to Database Page.
  2. Find the record that you want to edit. Note that you must be the owner of the record, which is indicated by the icon next to it on the Database page.
  3. Click on the icon. This will open this form in edit mode.
  4. Modify entries, detele data and add new information as needed.
  5. Click the Update button, then click Confirm.
Note that you cannot change the type of test. If you need to change the type of test, you will need to upload the record and save it as a new record with the different test type

For more information, please check the Tutorial page.
Download Records: You can download selected records in XML format using this form. Follow these steps:
  1. Either Load an existing record or fill out a new one
  2. Click the Download button, then click Confirm.
If all required fields are filled, the record will download immediately. If multiple tests were selected and completed, multiple records will be downloaded simultaneously. You can also download multiple records from the Database page in both XML and JSON formats.

For more information, please check the Tutorial page.

Fields marked with an asterisk (*) are required. If any required field is incomplete, the form will not be saved, downloaded, or updated. Please ensure all required fields are filled out. The form will indicate any missing fields and provide a clear message regarding the necessary information.

Semi-mandatory fields are those where at least one must be completed. The following fields are semi-mandatory:
  • For Grain Size Distribution, fill at least one of the following: Virgin Aggregates or Recovered Aggregates.
  • For Binder Content, fill at least one of the following: Binder Content in Mixture Recipe or Percentage Content of Recovered Binder.
  • For Penetration, fill at least one of the following: Virgin Binder Penetration or Recovered Binder Penetration.
  • For Voids, fill at least one of the following: Bulk density with Maximum density or Air voids.
