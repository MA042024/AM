Functionalities:
•   Extract records  
•   Validate records  
•   Save records  

Extract Records: You can extract records from the predefined AsphaltMine Excel sheet. To do this, follow these steps:
  1. Click on the Upload AsphaltMine Excel File button.
  2. Select the Excel file from your own device.
  3. Select one of the two available sheets: either the Columns sheet or the Rows sheet.
  4. Click Extract, then click Confirm.
Once the process is finished, a message will appear showing the number of records extracted, or if no records are extracted. This process could take some time depending on the size of the Excel sheet.

For more information, please check the Tutorial page.
Validate Records: You can validate the extracted records. This validation button will only appear if at least one record was extracted from the Excel sheet. To do this, click on the Validate button.

Once the records are successfully checked, you will see which records are valid and which are invalid. The screen will also display the reason for any invalid records.

For more information, please check the Tutorial page.
Save Records: Once all the records are valid, you can save them to the database at once by simply clicking the "Save" button that will appear after validation. The save button will only appear if all records are valid.

For more information, please check the Tutorial page.
