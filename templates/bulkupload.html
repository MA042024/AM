This page is used to bulk upload records using the predefined AsphaltMine Excel sheet.
Functionalities:
•   Validate records  
•   Save records  

Validate Records: You can validate multiple records from your own device. To do this, follow these steps:
  1. Click on the Upload Records button.
  2. Select multiple XML records from your own device.
  3. Click the Validate button.
Once the records are successfully loaded, you will see which records are valid and which are invalid. The screen will also display the reason for any invalid records.

For more information, please check the Tutorial page.
Save Records: Once all the records are valid, you can save them to the database at once by simply clicking the "Save" button that will appear after validation. The button will only appear if all records are valid.

For more information, please check the Tutorial page.
